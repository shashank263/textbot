🎯 WHAT IT DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TestBot is an AI-powered conversational assistant that:

✨ Understands vague hiring requests
   → "I'm hiring" triggers clarification: "What type of role? What level?"

🔍 Searches SHL catalog intelligently using FAISS vector search
   → "Java developer" → finds Java 8, Spring, and reasoning tests

📊 Ranks assessments using multi-factor algorithm
   → semantic similarity (50%) + skill overlap (30%) + role match (20%)

🔄 Supports refinement and conversation
   → "Actually, also need personality assessment" → adds OPQ32r

⚖️ Compares assessments
   → "Difference between OPQ and Situational Judgment?" → detailed comparison

🛡️ Protects scope with guardrails
   → Rejects: legal advice, salary questions, prompt injections
   → Only SHL assessments recommended

💬 Natural conversation (optional Ollama)
   → Works without Ollama using fallback templates

Step 1: Setup (2 minutes)
   cd s:\chatbotagent\testbot
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python setup.py

Step 2: Run (30 seconds)
   python -m uvicorn app.main:app --reload
   
   Server available at: http://localhost:8000

Step 3: Test (1 minute)

   python test.py

   curl -X POST http://localhost:8000/chat \
     -H "Content-Type: application/json" \
     -d '{"messages": [{"role": "user", "content": "Hiring Java developer"}]}'

🔌 API EXAMPLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example 1: Get Recommendations
   POST /chat
   {
     "messages": [
       {"role": "user", "content": "Hiring mid-level Java developer"}
     ]
   }
   
   Response: 
   {
     "reply": "Based on your requirements...",
     "recommendations": [
       {"name": "Java 8 (New)", "url": "...", "test_type": "K", ...}
     ],
     "end_of_conversation": false
   }

Example 2: Vague Request (Triggers Clarification)
   POST /chat
   {
     "messages": [
       {"role": "user", "content": "I'm hiring"}
     ]
   }
   
   Response:
   {
     "reply": "What type of role? What experience level?",
     "recommendations": [],
     "end_of_conversation": false
   }

Example 3: Compare Assessments
   POST /chat
   {
     "messages": [
       {"role": "user", "content": "Difference between OPQ32r and Verify Situational Judgment?"}
     ]
   }
   
   Response: Detailed comparison (duration, type, skills, level)

Example 4: Off-topic (Rejection)
   POST /chat
   {
     "messages": [
       {"role": "user", "content": "What's the average developer salary?"}
     ]
   }
   
   Response:
   {
     "reply": "I can't assist with salary. I'm specialized in SHL assessment recommendations.",
     "recommendations": [],
     "end_of_conversation": false
   }
